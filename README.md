# Legal-docs

Multi-app legal documents repository for GitHub Pages.

## Structure

Each app has its own folder containing a consistent set of legal documents:

```
Legal-docs/
├── index.html              ← Root landing page (lists all apps)
├── rank-pulse/             ← Rank Pulse — Teacher Exam Preparation
│   ├── index.html
│   ├── privacy-policy.html
│   ├── terms-and-conditions.html
│   ├── support.html
│   └── account-deletion.html
├── buzzinbeats/            ← Buzzin Beats — Music & Entertainment
│   ├── index.html
│   ├── privacy-policy.html
│   ├── terms-and-conditions.html
│   ├── support.html
│   └── account-deletion.html
└── taskbot/                ← TaskBot — Task Management
    ├── index.html
    ├── privacy-policy.html
    ├── terms-and-conditions.html
    ├── support.html
    └── account-deletion.html
```

## Adding a new app

1. Create a new folder (e.g., `new-app/`)
2. Copy the 5 files from any existing app folder
3. Update the app name, email, and content as needed
4. Add a link in the root `index.html`
